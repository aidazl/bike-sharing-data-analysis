# Bike Sharing Data Analysis Dashboard

An interactive data analysis dashboard developed using Python and Streamlit to explore bike sharing usage patterns and provide insights through data visualization.

This project was created as part of the Data Analytics with Python course by Dicoding.

---

## Project Overview

This dashboard analyzes bike sharing data to identify usage trends based on time, season, weather conditions, and user types. Interactive visualizations allow users to explore the dataset and better understand customer behaviour.

---

## Features

- Interactive data visualization
- Daily and hourly bike rental analysis
- Seasonal usage analysis
- Weather impact analysis
- User type comparison
- Streamlit dashboard interface

## Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/bike-sharing-dashboard.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the dashboard

```bash
streamlit run dashboard.py
```
